🧮 Calculadora em Python

Projeto desenvolvido durante meus estudos de Python, com o objetivo de praticar conceitos básicos de programação e lógica.

📌 Sobre o projeto

Uma calculadora simples executada pelo terminal, capaz de realizar as principais operações matemáticas:

➕ Adição
➖ Subtração
✖️ Multiplicação
➗ Divisão
⚠️ Validação de divisão por zero
❌ Validação de opção inválida
